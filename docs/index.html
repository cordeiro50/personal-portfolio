Final Project: Cybersecurity Infrastructure & Security Operations - UFCD 9197 CINEL

This final project involved the complete design and implementation of a complex corporate network infrastructure, integrating physical Cisco equipment (router and switches) with virtualized firewalls, servers, and security tools. The network was segmented into multiple VLANs (Red, Venus, Marte, and Management) with a VyOS router simulating physical connections and pfSense (VenusSuf) and OPNsense (MarteSuf) firewalls enforcing strict security policies across Green, Orange, and WAN zones. The infrastructure included a Windows Server 2022 Domain Controller with structured OUs, users, and groups, providing DHCP, DNS, and RADIUS authentication for VPN access, alongside Linux-based systems for vulnerability scanning (OpenVAS/Nessus), centralized logging (Syslog-ng with Grafana, Loki, and Promtail), and a Wazuh SIEM for threat detection and active response.

The project also featured the deployment of multiple VPNs (IPsec site-to-site, OpenVPN with RADIUS authentication, and WireGuard roadwarrior) to enable secure remote access between zones, as well as red team exercises including port scans, DOS attacks, and reverse shell exploitation from a Kali Linux machine. Security monitoring was reinforced with Snort (pfSense) and Suricata (OPNsense) intrusion detection systems, while web services were deployed on CentOS (Orange Venus) and Windows Core with IIS (Orange Marte), protected by a WAF with OWASP rules. The project was fully documented with detailed configurations, testing evidence, and validated against all functional requirements, demonstrating a comprehensive understanding of network security, system administration, and defensive operations in an enterprise environment.

Active Cybersecurity Infrastructure: Firewalls, VPNs & Secure Access Control - UFCD 9196 CINEL

NetCorp: Enterprise Network Infrastructure Project - UFCD 5106 CINEL

This project involved designing and implementing a complete corporate network for NetCorp, including a redundant Data Center and three branch offices. Using Cisco Packet Tracer, I configured VLANs with VTP and EtherChannel, implemented HSRP for gateway redundancy, and deployed dynamic routing protocols (OSPF, EIGRP, and RIP) with route redistribution across the network. Security measures included NAT overload (PAT) for Internet access, ACLs for traffic filtering, port-security, DHCP snooping, and Dynamic ARP Inspection at Layer 2.

Centralized authentication was established using AAA with TACACS+/RADIUS, along with IEEE 802.1X port-based access control and SSH for secure device management. A remote access VPN was also configured to enable secure connectivity between branches.
The project concluded with comprehensive testing of routing, NAT, ACLs, and security features.

Network Infrastructure & Security Implementation: VLAN Segmentation, AAA & Access Control - UFCD 5104 CINEL
